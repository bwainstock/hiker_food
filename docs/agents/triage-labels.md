# Triage Labels

Use these canonical labels to communicate an issue's next action.

| Label | Meaning |
| --- | --- |
| `needs-triage` | A maintainer needs to evaluate the issue |
| `needs-info` | The reporter must provide more information |
| `ready-for-agent` | The issue is fully specified and ready for an agent |
| `ready-for-human` | The issue requires human implementation |
| `wontfix` | The issue will not be worked on |

Apply exactly one of these labels when triage reaches a decision. Replace the
previous triage label when the issue's next action changes.
